# Interim Data

This directory is reserved for reproducible outputs from data cleaning and standardization.

Potential artifacts include standardized fisheries tables, parsed dates, validated coordinates, normalized labels, quality flags, and decoded environmental variables. Exact filenames and schemas will be defined only after the audit findings and field meanings are resolved.

Interim artifacts must:

- be generated by a version-controlled notebook or script;
- preserve a traceable link to the raw source and original row where feasible;
- record exclusions, corrections, and quality flags explicitly;
- avoid silently removing outliers, duplicates, or invalid records; and
- remain outside Git unless a small, non-sensitive sample is explicitly approved.

No interim dataset has been finalized yet.

# Processed Data

This directory is reserved for final modelling datasets produced from documented interim data.

A processed dataset may be created only after the following decisions are supported by evidence:

- authoritative fisheries sheets and fields;
- catch definition and unit;
- fishing-effort and CPUE feasibility;
- prediction target and forecast horizon;
- temporal aggregation method;
- spatial matching method; and
- leakage-safe feature availability.

Processed artifacts must be reproducible from raw data and version-controlled code. They must not be manually edited or committed to Git when they contain large, private, or restricted records.

No processed modelling dataset has been finalized yet.

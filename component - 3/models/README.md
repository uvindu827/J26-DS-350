# Trained model artifacts

This directory is reserved for trained Component 3 model pipelines generated by the machine-learning notebooks.

Model binaries such as `.joblib` files are intentionally excluded from Git because they are generated artifacts and may be very large. Keep the working copies in Google Drive under `MyDrive/FishGuard-C3/models/`, and copy them locally only when they are needed for evaluation or deployment.

Reproduce a model by running the corresponding version-controlled notebook and consulting its manifest under `outputs/audit/model_training/`.
